ВОЙНА ШАРИКОВ — версия для Unity
=================================

Это та же игра, что и HTML-версия: два острова, мост, лодки, танк, БТР,
Апач, казарма, умный враг, звук. Всё собирается кодом при запуске:
не нужно ни моделей, ни картинок, ни звуков, ни настройки сцены.

КАК ЗАПУСТИТЬ (если Unity ещё не стоит)
---------------------------------------
1. Скачай Unity Hub с сайта unity.com (кнопка Download) и установи.
2. Открой Hub, войди или зарегистрируйся. Возьми бесплатную лицензию
   Personal (Hub сам предложит).
3. Во вкладке Installs нажми Install Editor и выбери Unity 6
   (версия с пометкой LTS). Модули для Android/iOS не нужны.
4. Во вкладке Projects нажми New project, выбери шаблон
   "Universal 3D" (или просто "3D"), дай имя и нажми Create.
5. Когда проект откроется, перетащи всю папку WarOfBalls (ту, где лежит
   этот файл) в окно Project, в папку Assets.
6. Подожди, пока внизу справа закончится крутилка (Unity компилирует).
7. Нажми Play (треугольник сверху). Игра запустится сама в любой сцене.

Советы:
- В окне Game сверху выбери разрешение 1920x1080 или 16:9, а не
  Free Aspect — так интерфейс будет выглядеть правильно.
- Чтобы окно игры было на весь редактор, в верхней панели окна Game
  выбери "Play Maximized".
- Если в окне Console есть красные ошибки, сделай скриншот Console и
  пришли — поправлю.

УПРАВЛЕНИЕ
----------
ЛКМ по значку отряда — выбрать; потянуть от отряда — нарисовать путь
(до боя — переставить отряд). ЛКМ по пустому месту и тащить — двигать карту.
ПКМ — приказ выбранному отряду (идти / атаковать врага).
Shift + перетаскивание или средняя кнопка мыши — повернуть камеру.
Колесо мыши, кнопки + / − — зум. WASD или стрелки — двигать камеру.
Пробел — пауза. Q — артобстрел, E — боевой клич.
Кнопка 2D/3D справа — вид сверху.

СОБРАТЬ .EXE (необязательно)
---------------------------
File → Build Profiles → Windows → Build. Если в сборке вода или облака
выглядят неправильно: Edit → Project Settings → Graphics →
Always Included Shaders → добавь "Unlit/Transparent" и "Sprites/Default".

Файлы в Scripts:
  WB_Game   — запуск
  WB_Core   — константы, отряды, острова, мост, маршруты
  WB_Sim    — бой: движение, стрельба, лодки, флаги
  WB_AI     — мозги врага
  WB_World  — остров, море, небо, деревья, мост, лагеря
  WB_Render — бойцы, техника, камера, эффекты
  WB_Mesh   — построение 3D-фигур кодом
  WB_Draw2D — иконки и картинки интерфейса (рисуются кодом)
  WB_UI     — меню, казарма, HUD, управление
  WB_Audio  — звуки и музыка (синтезируются кодом)
Сохранение прогресса — через PlayerPrefs.
